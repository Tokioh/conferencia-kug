# 🌟 Skills de Desarrollo de Presentaciones

Esta carpeta contiene la **Skill oficial `conference-deck`** para desarrollar y extender presentaciones interactivas de alto impacto con el sistema de diseño **KotlinConf / JetBrains 2026**.

## 📁 Estructura

```text
skills/
└── conference-deck/
    ├── SKILL.md                          # Instrucciones completas para el agente de IA
    └── references/
        ├── design-tokens.css             # Tokens CSS, temas oscuros, cuadrículas y resplandores
        ├── slide-templates.md            # Catálogo con las 8 plantillas canónicas de diapositivas
        └── deck-engine-guide.md          # Control de estados, clickers y eventos de presentación
```

## 🚀 Uso en Antigravity y otros Asistentes

Copia la carpeta `conference-deck` a tu directorio global de skills (`~/.gemini/config/skills/` o `.agents/skills/`) para que el agente aplique automáticamente este estándar en cualquier nueva charla o keynote que desarrolles.
